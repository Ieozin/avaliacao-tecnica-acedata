# Avaliação Técnica - Acedata

Repositório com exercícios desenvolvidos para avaliação de lógica de programação.

## Tecnologias 
* Python 3

## Como executar

Clone o repositório:

```bash
git clone https://github.com/Ieozin/avaliacao-tecnica-acedata.git
cd avaliacao-tecnica-acedata
```

Execute o exercicio:

```bash
python exercicio_01_calculo_hora.py
python exercicio_02_sequencias_numeros.py
python exercicio_03_numeros_fibonacci.py
```
